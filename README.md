# clicq ads — Official Website

A professional 3D website for **clicq ads**, a performance advertising agency.

## 🚀 Deploy in 60 seconds (free)

### Option A — Vercel (recommended)
1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) → **Add New Project**
3. Import your GitHub repo → click **Deploy**
4. Add your custom domain in Project Settings → Domains

### Option B — Netlify
1. Push this repo to GitHub
2. Go to [netlify.com](https://netlify.com) → **Add new site** → Import from Git
3. Select your repo → click **Deploy site**
4. Add your domain under Site Settings → Domain management

### Option C — GitHub Pages
1. Push to GitHub
2. Go to repo **Settings** → **Pages**
3. Source: **Deploy from a branch** → `main` → `/root`
4. Your site will be live at `https://yourusername.github.io/clicq-ads-website`

## 🛠 Tech Stack
- Vanilla HTML / CSS / JS (no build step needed)
- [Three.js r128](https://threejs.org/) — 3D WebGL scene via CDN
- Google Fonts — Syne + Inter

## 📁 Structure
```
clicq-ads-website/
├── index.html      ← entire site (self-contained)
└── README.md
```

## ✏️ Customization
- **Colors** — edit CSS variables at the top of `index.html` (`:root` block)
- **Copy** — update text directly in the HTML
- **Email CTA** — replace `mailto:hello@clicqads.com` with your real email
- **Stats** — update the numbers in the `.stats-bar` section
